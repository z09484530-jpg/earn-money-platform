# TaskEarn Landing Page Demo

This project is a modern landing page mockup for a money-earning platform.

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` — main page structure
- `styles.css` — design and responsive layout
- `script.js` — small interactions

## Demo idea

- Dark premium fintech style
- Hero, stats, steps, features, reviews, CTA
- Mobile responsive design
